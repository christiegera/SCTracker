# Michael's Mission: Second Class 🚀

A space-themed fitness tracker for earning the Boy Scouts Second Class rank — specifically Requirement 7a (30 min/day, 5 days/week, 4 weeks).

## Features
- Activity logging (Walking, Hiking, Swimming, Mowing Lawn, Other)
- 20-day mission progress tracker
- Space joke reward on every log entry
- Mission medals for activity milestones
- Deep space fact cards
- Installable as a home screen app (PWA)

## Setup
1. Upload `index.html` and `manifest.json` to this repo
2. Enable GitHub Pages: Settings → Pages → Deploy from branch → main / root
3. Visit `https://[username].github.io/[repo-name]/`
4. On iPhone: tap Share → Add to Home Screen
5. On Android: tap the browser menu → Add to Home Screen / Install App

## Requirements Covered
BSA Second Class Rank — Requirement 7a:
> Participate in a physical fitness program. Do the following: (a) Complete the aerobic requirement... at least 30 minutes daily, five days a week, for four weeks.
